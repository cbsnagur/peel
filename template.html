Peel

Paste anything a computer handed you. Peel works out what it is and decodes it, layer by layer.

Runs in this tab. Nothing is sent anywhere.

Try one:

Recognizes JWTs, JSON (and repairs broken JSON or Python dicts), base64 with gzip or zlib inside, URLs and query strings, curl commands (converted to fetch and Python), cron schedules, Unix timestamps and dates, stack traces from JavaScript, Python, Java and Go, UUIDs, ULIDs, ObjectIds, hashes, hex, colors, CIDR blocks, HTTP status codes, PEM blocks, escaped strings and leaked API keys. You can also drop a text file on the box.
